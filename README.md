# PhysicParty — Fizik Tabanlı Co-Op Party Oyunu

Animasyonsuz, aktif ragdoll (Active Ragdoll) karakter mekaniklerine dayalı, co-op ve PvP odaklı eğlenceli bir fizik party oyunu.

## 🎮 Öne Çıkan Özellikler

* **Aktif Ragdoll Karakterler:** Gerçek zamanlı fizik ve IK destekli adım/yürüme sistemleri ile doğal ve komik karakter hareketleri.
* **Çeşitli Oyun Modları:**
  * **Saklambaç (Dust 2):** Saklananlar ebeyi eşyalarla bayıltmaya çalışır, ebe ise elindeki pompalı tüfekle saklananları avlar.
  * **Sıcak Patates:** Bombayı başkasına devret, patlamadan hayatta kal!
  * **Serbest (Sandbox) / Yıkım Bahçesi:** Tüm silahları, araçları ve parçalanabilir nesneleri serbestçe deneyebileceğiniz alan.
* **Gelişmiş Dövüş ve Silah Altyapısı:** Kılıç, balta, mızrak, arbalet, pompalı tüfek, kanca (grappling hook), bumerang ve daha fazlası.
* **Tam Senkronize Parçalanma Fiziği:** Nesneleri, ahşap yapıları ve kerpiç duvarları parçalayarak dinamik yollar açın.
* **Ağ & Çok Oyunculu (Co-Op / PvP):** Client-side prediction ve yumuşak düzeltme algoritmalarıyla düşük gecikmeli multiplayer deneyimi.

## 🛠️ Sistem Gereksinimleri & Kurulum

1. Projeyi klonlayın veya [Releases](../../releases) sayfasından son sürümü indirip zip arşivini çıkarın.
2. `PhysicParty.exe` dosyasını çalıştırın.
3. **Ana Menü** üzerinden yerel ağda (LAN) veya çevrimiçi oda kurarak arkadaşlarınızla oynayın.

## ⌨️ Temel Kontroller

| Tuş / Girdi | Eylem |
|---|---|
| **WASD / Shift / Space** | Yürü / Koş / Zıpla (Duvar veya İp başında: Tırman) |
| **Ctrl** | Çömel |
| **Sol / Sağ Tık** | Elle tutunma / Sol tık ile eşya savurma veya ateş etme / Sağ tık ile nişan alma |
| **E** | Yakındaki eşyayı / silahı al veya yerine koy |
| **1 - 2 - 3 / Fare Tekerleği** | Envanter slotu seçimi |
| **G / F** | Eşyayı yere bırak / Fırlat |
| **Q** | İleri atılma (Dive) |
| **Orta Tık** | Yumruk at (Basılı tutarak şarjlı yumruk) |
| **T** | Islık çal (Saklambaç modunda) |
| **B** | Mikrofona üfleme / Rüzgar çıkarma |
| **Esc** | Menü / Özelleştirme / Oda Ayarları |
